POST /api/remove

上传图片移除背景，返回 JSON（含 base64 图片数据）

请求参数 (multipart/form-data)
字段类型必填说明
imagefile✅图片文件 (PNG/JPG/WebP/BMP/TIFF)
modelstring❌模型ID，默认 birefnet-massive
可选 model 值
值说明
birefnet-massive最强模型（默认）
bria-rmbg商业级模型，速度更快
Response (成功)
{
  "success": true,
  "image": "data:image/png;base64,iVBORw0KGgo...",
  "filename": "a1b2c3d4_nobg.png",
  "download_url": "/api/download/a1b2c3d4_nobg.png",
  "model": "birefnet-massive",
  "model_name": "BiRefNet-Massive (最强)",
  "elapsed_seconds": 3.52,
  "original_size": [1920, 1080]
}
cURL 示例
curl -X POST http://127.0.0.1:5000/api/remove \
  -F "image=@photo.png" \
  -F "model=birefnet-massive"
POST /api/remove/file

上传图片移除背景，直接返回 PNG 文件流（适合程序调用）

请求参数 (multipart/form-data)
字段类型必填说明
imagefile✅图片文件
modelstring❌模型ID，默认 birefnet-massive
Response

直接返回 image/png 二进制流，Content-Type: image/png

cURL 示例
curl -X POST http://127.0.0.1:5000/api/remove/file \
  -F "image=@photo.png" \
  -o result_nobg.png
Python 示例
# 使用 /api/remove (返回 JSON + base64)
import requests

with open("photo.png", "rb") as f:
    resp = requests.post(
        "http://127.0.0.1:5000/api/remove",
        files={"image": f},
        data={"model": "birefnet-massive"}
    )
result = resp.json()
if result["success"]:
    import base64
    img_data = base64.b64decode(result["image"].split(",")[1])
    with open("result.png", "wb") as out:
        out.write(img_data)
    print(f"完成! 耗时: {result['elapsed_seconds']}s")

# 使用 /api/remove/file (直接返回文件)
with open("photo.png", "rb") as f:
    resp = requests.post(
        "http://127.0.0.1:5000/api/remove/file",
        files={"image": f},
        data={"model": "bria-rmbg"}
    )
with open("result.png", "wb") as out:
    out.write(resp.content)

URL 参数
参数说明

cURL 示例
