普通抠图 API 文档 分块抠图
分块抠图原理：把大图切成多个小块，每块单独抠图，再用余弦渐变权重在重叠区域平滑融合，最终合成一张完整的高分辨率透明 PNG。
适用场景：4K / 8K / 超大图、显存不够直接处理整图、对发丝等细节要求高的大图。
与普通抠图区别：普通模式整图缩放到模型输入尺寸（如 1024）后输出，大图细节会糊；分块模式保留原始分辨率，每块都跑满模型精度。
